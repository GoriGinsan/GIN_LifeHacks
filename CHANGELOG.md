# Changes

## Unreleased — Delay Key, smoother Pad drags

Timeline helper 1.2.0 + GIN Pad life hack 1.1.0 (Advanced mode helper 1.1.0 unchanged). Built; not yet run in the game.

GIN Pad life hack 1.1.0

- **Delay Key** (Body tab): every body part has its own delay in seconds (no frame steps; L.Shoulder can come 0.052 s after R.Shoulder). With `Delay Key` on, Auto Key of the Pad's own edits, `Key now` and a middle click write each part's key that long after the playhead, so a pose change starts at the hips and runs out through the body. Keys written any other way stay at the playhead. A key already at the delayed time is updated; keys in between are left alone; a time past the animation's end is moved to the end.
- **Delay bar** beside the figure: a small timeline standing up (playhead at the top). It is slim, so the window is no wider than before; in Edit mode the panel widens about three times and every part gets its own lane. Every part is a mark at its delay, the right side's parts on the left as on the figure. Drag a mark for its delay; drag between marks to stretch or shrink all delays; wheel: how many seconds the bar shows (0.1 to 5); right click a mark: 0, between marks: fit; double click: type the delay. Hovering a figure button lights its mark.
- **Edit** shows each part's delay on the figure's buttons and sets it there: drag up / down, Ctrl + click sets the origin (★), right click 0, double click to type. Dragging a part takes along every part further from the origin (dragging R.Shoulder moves R.Elbow and R.Hand); Alt moves only the part. Shift is four times finer and `Sens` applies, as everywhere in the Pad. While dragging, a large readout shows the delay, the difference to the other side's part (or the part towards the origin) and the key's time.
- Delays, the origin and the bar's length are remembered (`Body` settings); Delay Key itself is off after every Studio start. `Clear` (Ctrl + click) sets every delay to 0.
- **Smoother drags:** once a drag holds the cursor, its movement is applied once in every frame, as Move Controller does. Before, the value moved only in frames in which Windows sent a drag event, and with the parked cursor and a steadily moving mouse it often sent none, so bars, Body drags, the Move tab and the time button moved in steps.
- **Root** (Body tab): a small trapezoid in plain grey between the toes moves the whole character, Studio's own position of the character (its root guide object), not a bone or an IK target; its shape and grey keep it apart from the figure's buttons. Drag: floor plane as seen from the camera; right drag: up and down; click: select the root in Studio for its gizmo; middle click: key the character's position row at the playhead. It is not part of the figure's selection; Ctrl + Z undoes a move like any press on the tab (the pose snapshot now holds the root).
- **Time button:** a quarter of its former speed (2400 pixels cross the animation at `Sens` 1, at least 0.0025 s per pixel).

Timeline helper 1.2.0

- Writes the Pad's delayed keys: `NotePadEdit` tells Auto Key which transforms the Pad is editing and their delays (trusted for one second), and `KeyNamedRows` accepts `name=seconds`. The status line shows the delays used.

## v1.1.1 — Char Setup removed from the release

Bundle: Timeline helper 1.1.1 + Advanced mode helper 1.1.0 + GIN Pad life hack 1.0.0 (both unchanged).

- **Char Setup is no longer in the distributed Timeline helper:** on some installations it crashed the game. The release DLL has no `Char Setup` button and no embedded setup template; Auto Key, `+ Tracks`, the Advanced helper's `Timeline 0:00` buttons and GIN Pad's keys work as in 1.1.0. Rows, items and links that Char Setup already put into a scene are ordinary scene data and stay.
- **Two editions from one source:** `build.ps1` builds the Timeline helper with Char Setup (`bin`, the author's private edition, compile symbol `CHAR_SETUP`) and without it (`bin/public`, the release edition); `-Edition Private` / `Public` builds one. `package.py` packs the release edition by default and the private one with `--edition private` (ZIPs marked `_private`).

## v1.1.0 — Animation workflow

Bundle: Timeline helper 1.1.0 + Advanced mode helper 1.1.0 + GIN Pad life hack 1.0.0 (new). Scenes still contain only native Timeline, KKPE, Studio and Material Editor data.

Timeline helper

- **Char Setup** follows the author's new setup scene (template generated by `src/tools/extract_character_setup.py`): the five row groups plus `O_BODY_A` in the scene's order, `BODY` with `cf_d_shoulder_L` / `_R` and `cf_d_kokan`, the items around the character with the scene's sizes (breath steams, anchor sphere, STRINGS folder, splash, mist, fog, a hidden stream sphere with its water streams), Material Editor settings, the NodesConstraints link between the anchor and the stream sphere, and the `STREAM`, `FOG` and `STRINGS` rows. The second to fifth character get their own colour theme. Existing items, links and rows are kept; rows outside their group are moved into it.
- **Auto Key:** while on and stopped, moving something that already has a row writes that row's key at the playhead (update or insert). A small Blender-style record button (blue with a red dot while on) and a red line mark the state; the arrow beside it chooses the curve of added keys (previous key's curve, or Line / Top / Bottom / Hermite / Stairs). S keeps working; Auto Key is off after every Studio start.
- **Open / close all folders:** Ctrl + click on a folder's open / close arrow sets every folder to the clicked folder's new state.
- **Endless drags** (GIN Pad and the Advanced helper): a drag that changes a value by how far the mouse moves (the Pad's bars and `Sens`, the Body figure's buttons, the Move tab's square, turns and `Anim`, the Pad's time button, the Advanced helper's Bones +/- scrubs) no longer stops at the edge of the screen. As in Move Controller, once the drag moves the cursor is hidden and the mouse's own movement is used; it is parked in the middle of the game's screen meanwhile and comes back where the drag began when the button is released. It runs as fast as the visible cursor did (measured from the cursor's ordinary movement, Windows' pointer speed and acceleration included). The Map, the gaze, scroll bars and window moves follow the pointer as before.
- **Keying by name** for GIN Pad: rows of named bones, guide objects or renderers are keyed at the playhead (a key already there is updated).
- **Reordering:** plain Up / Down are the new defaults (Shift + Up / Down defaults are migrated once). Neighbouring selected rows or groups now move as one block and stop together at the top or bottom instead of swapping with each other.
- Cached reflection and companion-plugin lookups that previously ran several times per frame; toolbar built from one table; one version constant.

Advanced mode helper

- **Timeline 0:00 buttons** in the Blend Shapes tab: `Key all` and `Key filtered` register the selected renderer's Blend Shapes as Timeline rows with a 0:00 key. Face and eyebrow renderers become one linked group row; other renderers get one row per Blend Shape. Requires the Timeline helper 1.1.0.
- **Eyelash fix:** applying a saved expression now follows KKPE's eye link (eyelashes, tears), as Timeline's linked group rows do. Before, the eyelashes stayed behind when an expression closed the eyes, until the Timeline was moved.
- Cached KKPE type and member lookups used for every row on every GUI event.

GIN Pad life hack 1.0.0 (new plugin)

- Opened with the `IK QOL` button on Studio's left toolbar (KKAPI) or an optional key; works without KKPE's Advanced mode window. The tabs follow Studio's selection: character tabs for a character, item tabs as soon as anything else is selected (several objects included). Window that always shrinks to its contents, sized by `UiScale` (1.045, 5 % smaller than before; a saved 1.1 follows once) or by dragging the small round knob outside its top right corner (proportions kept, 0.6 to 2, remembered; right click: default); play / pause and a time drag with a large time readout outside its top left corner (these replace the tiny buttons the Timeline helper had put on Studio's toolbar); 50 % translucent background with solid buttons. Studio's camera, its move / rotate / scale gizmos and its UI ignore every mouse action on the window; a press is claimed from the window's own GUI event too. Lists use the Pad's own scroll bar instead of IMGUI's.
- **Drag bars** replace sliders everywhere: press anywhere on the bar and move; adjustable sensitivity (default 0.6), Shift for fine steps, right click for the default.
- **Tabs side by side:** Map, Face, Body and Shapes (the body Blend Shapes) are toggles; every open tab is shown next to the others, and the open tabs are remembered. Tabs other than the Map are about 15 % narrower.
- **Face tab:** Blend Shapes of eyes, mouth, eyebrows and teeth, listed by `Fav` (pinned only), `Used` (pinned, raised by a Timeline key, or not zero; the five `def` shapes left out) or `All`.
- **Pupil limits:** X clamped per pupil (left -0.017 .. 0.013, right mirrored) and Z set from X (-0.0015 at the nose side to -0.0030 at the outer side). The nose side is measured on the character.
- **Map tab:** 28 mouth poses x 20 eye poses on one graph (381 x 400) with blending in between, gaze on the right mouse button, Shift + drag for one direction only; below it `Brows` | `Spread` and `L / R height` | `Size` in two rows with `Center` and `Limit`. The default poses are the author's own map (`src/tools/map_file_to_default.py`); a click on a triangle goes straight to a pose; a pose editor beside the map (small triangle per pose) changes any pose with the Face tab's bars, stores the current face as a pose, reorders, adds and deletes poses, and saves by itself.
- **Body tab:** IK targets and the bones KKPE's small window lacks (head, neck, waist02, bust01 / bust03, siri01, toes) on a figure of large buttons. Ctrl + click selects several IK targets or several bones (never mixed); all of them move or turn the same way on screen. Dragging on a button turns a bone freely or moves an IK target on the floor plane, the right button rolls / lifts, a middle click resets a bone's rotation. Tall red / green / blue X / Y / Z bars, KKPE's limb copy and swap functions, `Key now`, `o_body_a` Blend Shapes beside the figure (bars as long as the Face tab's). Dragged on the figure the neck bends only on X / Z and the shoulder joints swing only on Y. The tab is 10 % narrower than the other tabs. Each press on the tab is one step of Studio's Undo (Ctrl + Z), KKPE's bone overrides, resets, limb copies and `Swap pose` included. Blend Shape names that use dots themselves (GIN Kupaa3 `P.Open1.L`, `S.Huge.R`, GIN Puffy `vagina.open`) are shown whole instead of as `L` / `R` / `open`.
- **Keys:** the Timeline's Auto Key keys Pad edits; a middle click on any bar or on the Map keys the tab's rows at the playhead through the Timeline helper.
- **Move tab (items):** Move Controller's square (floor / height), camera-relative and own-axis turns, 90-degree clicks, To camera, Anim scrubbing, Reset FK and FK node stepping with the mouse wheel; one Studio Undo step per edit.
- **Shapes tab (items):** the selected item's Blend Shapes through KKPE. The first edit switches KKPE on for a newly added item, so its right click > `Enable` is no longer needed.

Timeline and Advanced: unused `using` directives removed from every source file.

## v1.0.3 — Timeline interaction fixes and first GitHub distribution

Bundle: Timeline helper 1.0.3 + Advanced mode helper 1.0.2.

- Group summary keys now follow native red/green selection colors.
- Native box selection includes real descendant keys represented on group rows.
- Alt dragging works for collapsed groups and mixed visible/hidden selections, with ShalltyUtils Performance Mode enabled or disabled.
- A destination collision rejects the complete group move before changing keys.
- Default insertion is Ctrl + right click, configurable through F1. Native middle click remains available.
- S invokes native Use Current Value after viewport/KKPE manipulation without requiring Timeline pointer focus. Default S permits held Shift/Alt and reserves Ctrl+S for scene save.
- Actual text fields, IME composition and the F1 settings screen suppress editing shortcuts.
- Installed DLL filenames no longer contain versions. ZIPs contain only BepInEx/plugins and runtime DLLs; documentation and source are maintained in this repository.

The runtime DLL contents are the same verified Timeline 1.0.3 and Advanced 1.0.2 binaries previously distributed with versioned filenames. Only the installation filenames and ZIP contents were changed for publication.
